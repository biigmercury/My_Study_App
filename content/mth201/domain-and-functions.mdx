# Domain and Functions

A function is one of the most fundamental ideas in all of mathematics. Every equation you write, every graph you draw, every physical model you build — they all rely on the concept of a function. Understanding what a function is, what its domain and range are, and how to find them is the starting point of this entire course.

## What Is a Function?

Let $X$ and $Y$ be two non-empty sets. A **function** $f$ from $X$ to $Y$ is a rule that assigns to each element in $X$ exactly one element in $Y$. We write:

$$f: X \to Y$$

The elements of $X$ are the **inputs** (independent variables); the elements of $Y$ are the **outputs** (dependent variables).

**Two conditions for a valid function:**
1. Every element in $X$ must be assigned some element in $Y$ — no inputs left unassigned.
2. No element in $X$ is assigned more than one output — each input gives a unique output.

**Real-world analogy:** Think of a vending machine. Each button (input) gives exactly one product (output). If one button gives two different products randomly, it's not a proper vending machine function. If some buttons don't work at all, those inputs are outside the domain.

### Notation

$y = f(x)$ — "y is a function of x." Here $f$ names the function, $x$ is the input, and $y$ is the output.

---

## Real-Valued Functions

A **real-valued function** maps real numbers to real numbers:

$$f: \mathbb{R} \to \mathbb{R}$$

**Common types:**

| Type | Example |
|---|---|
| Algebraic | $f(x) = x^2 + 3x + 5$ |
| Trigonometric | $\sin x$, $\cos x$, $\tan x$ |
| Logarithmic | $\log x$, $\ln x$ |
| Exponential | $e^x$, $2^{x+3}$ |
| Modulus | $|x|$, $|2x+3|$ |
| Square root | $\sqrt{x}$, $\sqrt{x-4}$ |

---

## Domain, Co-domain, and Range

- **Domain** $D_f$: the set of all input values $x$ for which $f(x)$ is defined (gives a real output).
- **Co-domain**: the set $Y$ of all possible outputs — what the function *could* produce.
- **Range** $R_f$: the set of actual outputs obtained — always a subset of the co-domain.

$$R_f \subseteq \text{Co-domain}$$

**Real-world analogy:** The domain is the list of valid addresses a postal service delivers to. The range is the set of addresses that actually received mail today. The co-domain is every address in the city.

---

## Finding the Domain

The domain is restricted by four main problems:

1. **Division by zero** — exclude values making the denominator zero.
2. **Square root of negative** — the radicand (expression under $\sqrt{\phantom{x}}$) must be $\geq 0$.
3. **Logarithm of non-positive** — the argument of $\ln$ or $\log$ must be $> 0$.
4. **Even roots of negatives** — same as square root rule for fourth roots, etc.

---

## Example 1 — Finding Domains

Find the domain of each function:

**(i)** $f(x) = 5x + 3$

No restrictions — any real $x$ works.
$$D = \mathbb{R} = (-\infty, \infty)$$

**(ii)** $g(x) = 2\sqrt{x - 4}$

The radicand must be $\geq 0$:
$$x - 4 \geq 0 \implies x \geq 4$$
$$D = [4, \infty)$$

**(iii)** $g(t) = \sqrt{6 + t - t^2}$

Set radicand $\geq 0$:
$$6 + t - t^2 \geq 0 \implies t^2 - t - 6 \leq 0 \implies (t-3)(t+2) \leq 0$$

The parabola $(t-3)(t+2)$ is $\leq 0$ between its roots $t = -2$ and $t = 3$.
$$D = [-2, 3]$$

**(iv)** $F(x) = \dfrac{x-4}{x^2 - 2x - 15}$

Set denominator $\neq 0$:
$$x^2 - 2x - 15 = 0 \implies (x-5)(x+3) = 0 \implies x = 5 \text{ or } x = -3$$
$$D = (-\infty, -3) \cup (-3, 5) \cup (5, \infty)$$

## Finding the Range

The range depends on the function type:

| Function type | Range |
|---|---|
| Linear $f(x) = mx + b$ | $\mathbb{R}$ |
| Quadratic $y = a(x-h)^2 + k$ | $[k, \infty)$ if $a>0$; $(-\infty, k]$ if $a < 0$ |
| Square root | $[0, \infty)$ |
| Exponential $a^x$, $a > 0$ | $(0, \infty)$ |
| Logarithmic | $\mathbb{R}$ |
| Absolute value | $[0, \infty)$ |
| Rational $y = f(x)$ | Solve for $x$, exclude values where denominator $= 0$ |

---

## Example 2 — Finding Ranges

Find the range of each function:

**(i)** $g(x) = 2\sqrt{x - 4}$

Domain is $x \geq 4$. At $x = 4$: $g(4) = 0$. As $x$ increases, $g(x)$ increases without bound.
$$R = [0, \infty)$$

**(ii)** $h(x) = -2x^2 + 4x - 9$

Complete the square:
$$h(x) = -2(x^2 - 2x) - 9 = -2(x^2 - 2x + 1 - 1) - 9 = -2(x-1)^2 - 7$$

This is a downward parabola with vertex $(1, -7)$. Maximum value is $-7$.
$$R = (-\infty, -7]$$

**(iii)** $F(x) = \dfrac{x+2}{x-3}$

Solve for $x$:
$$y = \frac{x+2}{x-3} \implies y(x-3) = x+2 \implies x(y-1) = 2+3y \implies x = \frac{2+3y}{y-1}$$

The denominator $y - 1 \neq 0$, so $y \neq 1$.
$$R = \{y \in \mathbb{R} \mid y \neq 1\} = (-\infty, 1) \cup (1, \infty)$$

**(iv)** $y = \ln(x + 2)$

The natural logarithm takes all real values as output.
$$R = \mathbb{R}$$

## Practice Domain Problems (Selected Solutions)

**$f(x) = \dfrac{1}{x-4}$:** Set $x - 4 \neq 0 \Rightarrow x \neq 4$. Domain: $(-\infty, 4) \cup (4, \infty)$.

**$h(x) = \log_2(x-4)$:** Set $x - 4 > 0 \Rightarrow x > 4$. Domain: $(4, \infty)$.

**$F(x) = \sqrt{4x - x^2 - 3}$:**
$$4x - x^2 - 3 \geq 0 \implies x^2 - 4x + 3 \leq 0 \implies (x-1)(x-3) \leq 0$$
Domain: $[1, 3]$.

**$f(x) = \sqrt{\dfrac{9-x^2}{x}}$:**
Need $\frac{9-x^2}{x} \geq 0$ and $x \neq 0$.
$9-x^2 \geq 0 \Rightarrow -3 \leq x \leq 3$. Combined with $x \neq 0$: Domain $= [-3, 0) \cup (0, 3]$.

## Key Takeaways

- A function assigns each input exactly one output — the uniqueness of output is what makes it a function.
- The **domain** is the set of valid inputs; the **range** is the set of actual outputs.
- To find the domain: identify and exclude values that cause division by zero, square roots of negatives, or logarithms of non-positives.
- To find the range: use the known range rules for standard functions, or solve for $x$ in terms of $y$ and identify impossible $y$ values.
- Range $\subseteq$ Co-domain — the range is never larger than the co-domain.

---

## Exam Tips

- For domain questions: write out the restriction condition (e.g., radicand $\geq 0$), solve it, and state the answer in interval notation.
- When multiple restrictions apply (e.g., both a square root and a denominator), find each restriction separately then take the **intersection** of the valid sets.
- For $\sqrt{f(x)}$, the solution is where $f(x) \geq 0$ — find the roots of $f(x)$ and test intervals.
- For range of rational functions: don't just stare at it — make $x$ the subject and find what $y$ values make the denominator zero.
- At UI, domain questions often involve square roots with quadratics under them. Factorise the quadratic, find roots, then test intervals to determine the sign.
