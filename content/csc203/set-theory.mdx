# Set Theory

If Logic provides the rules for how we think, **Set Theory** provides the containers for what we think about. In fact, you will quickly discover that Logic and Set Theory are practically mirror images of each other.

A **Set** is simply a collection of distinct objects. These objects are called **elements** or **members** of the set. 

> **Real World Analogy:** Think of a Set as a shopping bag. The items inside the bag (the apples, the milk, the bread) are the elements. If you drop a second apple into the bag, it doesn't really matter—the bag still just contains "apples, milk, and bread". Order doesn't matter, and duplicates don't matter.

## Notation and Definitions

If an element $a$ is inside the set $A$, we write **$a \in A$**.
If it is not, we write **$a \notin A$**.

We typically define sets using curly braces.
$A = \{1, 2, 3, 4\}$

There are several **Standard Sets** in mathematics that you must memorize:
- $\mathbb{N}$: Natural Numbers $\{0, 1, 2, 3, ...\}$
- $\mathbb{Z}$: Integers $\{..., -2, -1, 0, 1, 2, ...\}$
- $\mathbb{Z}^+$: Positive Integers $\{1, 2, 3, 4, ...\}$
- $\mathbb{R}$: Real Numbers (every number on the number line, including decimals and Pi)
- $\mathbb{Q}$: Rational Numbers (any number that can be written as a fraction $a/b$)

### Set Builder Notation
Sometimes a set is too large to list out manually. We use **Set Builder Notation** to describe the rules for getting into the set.

$A = \{x \mid x \in \mathbb{N} \land x > 7\}$

We read this as: "The set of all $x$, such that $x$ belongs to the Natural Numbers AND $x$ is greater than 7." This generates the set $\{8, 9, 10, ...\}$.

## Relationships Between Sets

### 1. Equality ($A = B$)
Two sets are equal if and only if they contain the exact same elements. Remember, order and duplicates are meaningless!
- $\{9, 2, 7, -3\} = \{7, 9, -3, 2\}$
- $\{dog, cat, horse\} = \{cat, horse, dog, dog\}$

### 2. Subsets ($A \subseteq B$)
We say $A$ is a subset of $B$ if **every** element in $A$ is also found inside $B$.
- If $A = \{3, 9\}$ and $B = \{5, 9, 1, 3\}$, then $A \subseteq B$ is True.

**Two critical rules to memorize:**
1. The Empty Set ($\emptyset$) is a subset of every set. $\emptyset \subseteq A$.
2. Every set is a subset of itself. $A \subseteq A$.

### 3. Proper Subsets ($A \subset B$)
If we want to say that $A$ is a subset of $B$, BUT $A$ is strictly smaller than $B$ (they are not equal), we use the proper subset symbol.
$A \subset B \iff \forall x (x \in A \rightarrow x \in B) \land \exists x (x \in B \land x \notin A)$

## The Power Set

The **Power Set** of $A$, denoted $\mathcal{P}(A)$, is a massive set that contains **every possible subset** of $A$.

### Worked Example 1: Building a Power Set
Let $A = \{x, y\}$. What is $\mathcal{P}(A)$?

To build it, we list out every possible combination of elements we could extract:
1. We could extract nothing: $\emptyset$
2. We could extract single items: $\{x\}, \{y\}$
3. We could extract everything: $\{x, y\}$

Therefore, $\mathcal{P}(A) = \{\emptyset, \{x\}, \{y\}, \{x, y\}\}$.

> **Cardinality Formula:** If a set $A$ has $n$ elements (written as $|A| = n$), its Power Set will always have exactly $2^n$ elements. In our example, $A$ had 2 elements, and $\mathcal{P}(A)$ had $2^2 = 4$ elements.

## Set Operations

Just like logical operators ($\land, \lor$), we have operations to combine sets. Let's visualize them.

1. **Union ($A \cup B$):** The combination of everything in $A$ OR $B$. 
   - $A \cup B = \{x \mid x \in A \lor x \in B\}$
2. **Intersection ($A \cap B$):** Only the elements that exist in BOTH $A$ AND $B$.
   - $A \cap B = \{x \mid x \in A \land x \in B\}$
3. **Difference ($A - B$):** The elements in $A$ that are NOT in $B$. (Take $A$, and subtract anything that overlaps with $B$).
   - $A - B = \{x \mid x \in A \land x \notin B\}$
4. **Complement ($A^c$ or $\bar{A}$):** Everything in the entire universe that is NOT in $A$.
   - $A^c = U - A$

If the intersection of two sets is empty ($A \cap B = \emptyset$), we call those sets **Disjoint**.

## Cartesian Product

The **Cartesian Product** ($A \times B$) is how we generate coordinate pairs. We take every element from $A$ and pair it with every element from $B$.

### Worked Example 2: Cartesian Product
Let $A = \{good, bad\}$ and $B = \{student, prof\}$.

$A \times B = \{(good, student), (good, prof), (bad, student), (bad, prof)\}$

Notice that the order within the parentheses matters! $(good, student)$ is not the same as $(student, good)$. Therefore, $A \times B \neq B \times A$.

---

### Key Takeaways
- **Sets** are unordered, unique collections of elements.
- The **Power Set** $\mathcal{P}(A)$ contains all subsets of $A$ and always has $2^n$ elements.
- **Set Operations** ($\cup, \cap, -$) map directly to Logical Operators ($\lor, \land, \neg$).
- The **Cartesian Product** generates ordered pairs and is the foundation for defining Relations and Databases.

### Exam Tips
- **The Empty Set Trap:** Be very careful with the difference between the empty set $\emptyset$ and a set containing the empty set $\{\emptyset\}$. The cardinality of $\emptyset$ is $0$. The cardinality of $\{\emptyset\}$ is $1$.
- **Subset vs Element:** Remember that $3 \in \{1, 2, 3\}$, but $\{3\} \subseteq \{1, 2, 3\}$. Do not mix up the "is an element of" ($\in$) and "is a subset of" ($\subseteq$) symbols in proofs.
