## The Goal

In the previous topic we learned to write recurrences. Now we solve them — we turn equations like $T(n) = 2T(n/2) + n$ into closed-form answers like $O(n \log n)$.

There are three standard methods:
1. **Substitution (Unrolling)** — expand the recurrence by hand until a pattern emerges
2. **Recursion Tree** — visualise the work done at each level of recursion
3. **Master Theorem** — a formula that handles divide-and-conquer recurrences directly

---

## Method 1: Substitution (Unrolling)

**Idea:** Replace $T(n)$ with the right-hand side repeatedly until you see the pattern, then sum up.

### Example: $T(n) = T(n-1) + 1$, $T(1) = 1$

**Unroll:**
$$T(n) = T(n-1) + 1$$
$$= T(n-2) + 1 + 1 = T(n-2) + 2$$
$$= T(n-3) + 3$$
$$= \cdots$$
$$= T(n-k) + k$$

When $k = n-1$: $T(n) = T(1) + (n-1) = 1 + (n-1) = n$.

$$\boxed{T(n) = O(n)}$$

### Example: $T(n) = T(n/2) + 1$, $T(1) = 1$

**Unroll:**
$$T(n) = T(n/2) + 1$$
$$= T(n/4) + 1 + 1 = T(n/4) + 2$$
$$= T(n/8) + 3$$
$$= T(n/2^k) + k$$

When $n/2^k = 1 \Rightarrow k = \log_2 n$:

$$T(n) = T(1) + \log_2 n = 1 + \log_2 n$$

$$\boxed{T(n) = O(\log n)}$$

### Example: $T(n) = 2T(n-1) + 1$, $T(1) = 1$ (Tower of Hanoi)

**Unroll:**
$$T(n) = 2T(n-1) + 1$$
$$= 2(2T(n-2) + 1) + 1 = 4T(n-2) + 2 + 1$$
$$= 4(2T(n-3) + 1) + 3 = 8T(n-3) + 4 + 2 + 1$$
$$= 2^k T(n-k) + (2^k - 1)$$

When $k = n-1$:
$$T(n) = 2^{n-1} T(1) + (2^{n-1} - 1) = 2^{n-1} + 2^{n-1} - 1 = 2^n - 1$$

$$\boxed{T(n) = O(2^n)}$$

## Method 2: Recursion Trees

**Idea:** Draw the tree of recursive calls. At each level, calculate the total work done. Sum across all levels.

### Example: $T(n) = 2T(n/2) + n$ (Merge Sort)

**The tree:**

```
Level 0:    n                         ← cost: n
           / \
Level 1: n/2  n/2                    ← cost: n/2 + n/2 = n
        / \ / \
Level 2: n/4 n/4 n/4 n/4             ← cost: 4×(n/4) = n
           ...
Level k:  2^k nodes of size n/2^k    ← cost: 2^k × (n/2^k) = n
           ...
Level log n: n nodes of size 1        ← cost: n×1 = n
```

- Work per level: $n$
- Total levels: $\log_2 n + 1$

$$T(n) = n(\log_2 n + 1) = O(n \log n)$$

### Example: $T(n) = 3T(n/4) + n^2$

**The tree:**

```
Level 0:   n²                         ← cost: n²
          /|\
Level 1: 3×(n/4)²                    ← cost: 3(n/4)² = 3n²/16
        /|\ /|\ /|\
Level 2: 9×(n/16)²                   ← cost: 9(n/16)² = 9n²/256
```

**Each level's cost:** Level $k$ has $3^k$ nodes of size $n/4^k$. Cost = $3^k \times (n/4^k)^2 = n^2 (3/16)^k$.

**Total (geometric series):**

$$T(n) = \sum_{k=0}^{\log_4 n} n^2 (3/16)^k = n^2 \sum_{k=0}^{\infty} (3/16)^k = n^2 \cdot \frac{1}{1 - 3/16} = n^2 \cdot \frac{16}{13} = O(n^2)$$

The series converges because $3/16 < 1$ — the root dominates, giving $O(n^2)$.

## Method 3: The Master Theorem

The most powerful tool for divide-and-conquer recurrences of the form:

$$T(n) = aT(n/b) + f(n)$$

where $a \geq 1$, $b > 1$, $f(n)$ is a given function.

### The Key Quantity: $n^{\log_b a}$

The quantity $n^{\log_b a}$ is the total number of leaves in the recursion tree (each leaf does $O(1)$ work). This is what the non-recursive work $f(n)$ is compared against.

### The Three Cases

**Case 1:** $f(n) = O(n^{\log_b a - \varepsilon})$ for some $\varepsilon > 0$

$f$ grows strictly slower than $n^{\log_b a}$ (the leaves dominate).

$$T(n) = \Theta(n^{\log_b a})$$

**Case 2:** $f(n) = \Theta(n^{\log_b a})$

$f$ and $n^{\log_b a}$ grow at the same rate (each level contributes equally).

$$T(n) = \Theta(n^{\log_b a} \log n)$$

**Case 3:** $f(n) = \Omega(n^{\log_b a + \varepsilon})$ for some $\varepsilon > 0$, AND $af(n/b) \leq cf(n)$ for some $c < 1$

$f$ grows strictly faster than $n^{\log_b a}$ (the root dominates).

$$T(n) = \Theta(f(n))$$

## Worked Examples: Master Theorem

### Example 1: Binary Search — $T(n) = T(n/2) + 1$

$a=1$, $b=2$, $f(n)=1$.

$n^{\log_b a} = n^{\log_2 1} = n^0 = 1$.

$f(n) = 1 = \Theta(1) = \Theta(n^{\log_2 1})$ → **Case 2**.

$$T(n) = \Theta(\log n)$$

### Example 2: Merge Sort — $T(n) = 2T(n/2) + n$

$a=2$, $b=2$, $f(n)=n$.

$n^{\log_b a} = n^{\log_2 2} = n^1 = n$.

$f(n) = n = \Theta(n)$ → **Case 2**.

$$T(n) = \Theta(n \log n)$$

### Example 3: Strassen — $T(n) = 7T(n/2) + n^2$

$a=7$, $b=2$, $f(n)=n^2$.

$n^{\log_b a} = n^{\log_2 7} \approx n^{2.807}$.

$f(n) = n^2 = O(n^{2.807 - 0.807})$ → **Case 1** ($\varepsilon = 0.807$).

$$T(n) = \Theta(n^{\log_2 7}) \approx O(n^{2.807})$$

### Example 4: $T(n) = 4T(n/2) + n^3$

$a=4$, $b=2$, $f(n)=n^3$.

$n^{\log_b a} = n^{\log_2 4} = n^2$.

$f(n) = n^3 = \Omega(n^{2+1})$ — grows faster → **Case 3**.  
Check: $af(n/b) = 4(n/2)^3 = n^3/2 = (1/2)f(n) \leq cf(n)$ with $c = 1/2 < 1$. ✓

$$T(n) = \Theta(n^3)$$

### Example 5: $T(n) = 2T(n/2) + n \log n$

$a=2$, $b=2$, $n^{\log_b a} = n$.

$f(n) = n \log n$. Is $f(n) = \Theta(n)$? No — $n \log n$ grows faster than $n$.  
Is $f(n) = \Omega(n^{1+\varepsilon})$ for some $\varepsilon > 0$? Also no — $n \log n = o(n^{1+\varepsilon})$ for any $\varepsilon > 0$.

**The Master Theorem does NOT apply here.** Use substitution or recursion tree:

$$T(n) = O(n \log^2 n)$$

## Key Takeaway

> Three methods solve recurrences: (1) **Substitution**: unroll $k$ steps, spot the pattern, substitute the base case; (2) **Recursion tree**: compute work per level and sum across all levels; (3) **Master Theorem**: compare $f(n)$ to $n^{\log_b a}$ — if $f$ is smaller, the leaves dominate (Case 1); if equal, logarithm factor appears (Case 2); if $f$ is larger, the root dominates (Case 3). The Master Theorem is the fastest method for standard divide-and-conquer recurrences.

## Exam Tips

**What lecturers test:**
- Apply Master Theorem to 3–4 recurrences and state which case applies
- Solve $T(n) = T(n-1) + c$ by unrolling
- Build a recursion tree for $T(n) = 2T(n/2) + n$ and show work per level
- Identify recurrences where Master Theorem does NOT apply

**Common mistakes:**
- Applying Case 3 without checking the regularity condition $af(n/b) \leq cf(n)$
- Confusing $n^{\log_b a}$ with $\log_b(a^n)$ — remember it is $n$ to the power $\log_b a$, not anything else
- Forgetting the $\log n$ factor in Case 2 (the answer is $\Theta(n^{\log_b a} \log n)$, not just $\Theta(n^{\log_b a})$)

**Likely question:**
> "Solve the following recurrences using the Master Theorem. State which case applies and justify: (a) $T(n)=4T(n/2)+n$, (b) $T(n)=2T(n/2)+n\log n$, (c) $T(n)=8T(n/3)+n^2$." (12 marks)
