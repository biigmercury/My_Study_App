## Microsoft Word in One Sentence

**Microsoft Word** is a **word processor**: a program for **creating, editing, formatting, saving and printing documents** — letters, reports, CVs, assignments, memos, flyers. A Word file is a **document** (`.docx`; `.doc` for Word 97–2003).

This lesson is your map of the Word 2013 environment: how to start it, what every part of the window is called, and where the commands live. The next three lessons use this map to type, format, edit and lay out real documents.

---

## Launching Word 2013

| Windows version | Steps |
|---|---|
| **Windows 7** | Click **Start** → type `Word` in the **Start Search** field → select **Word 2013** from the results |
| **Windows 8** (Start screen showing) | Just start typing `Word` → select **Word 2013** |
| **Windows 8** (desktop showing) | Click **Start** (or press the Windows key) → type `Word` → select **Word 2013** |
| **Windows 10 / 11** | Type `Word` in the **search box** on the taskbar (bottom-left) → select Word |

You can also double-click an existing `.docx` file, or use a desktop/taskbar shortcut.

### The Start Screen

The **Start Screen** is new in Office 2013. Instead of opening straight into a blank page, Word first shows:

- **Recent** documents on the **left**, with **Open Other Documents** to browse for a file not listed;
- **templates** in the preview area on the **right** — letters, labels, reports, event flyers, CVs — and a box to **search online templates**. Clicking a template shows a preview and information about it before you create it.

Most of the time you will choose **Blank document** because you already know what you want to type.

If a Word document is **already open**, starting another document goes straight to a blank page. The Start Screen can be switched off in **FILE → Options → General** (untick *Show the Start screen when this application starts*); Word then opens a blank document at start-up, like older versions.

## The Word Window

Choosing **Blank document** opens the standard Word window. Word automatically names the new file **Document1** until you save it with a name. The page is shown in **Print Layout** view — exactly as it will print.

![The Word 2013 window with numbered labels: 1 Quick Access Toolbar, 2 title bar reading Document1 - Word, 3 help, minimize, maximize and close buttons, 4 FILE tab, 5 ribbon tabs HOME INSERT DESIGN PAGE LAYOUT REFERENCES MAILINGS REVIEW VIEW, 6 ribbon groups Clipboard Font Paragraph Styles Editing, 7 dialog box launcher arrow, 8 ruler with indent markers, 9 document area with the insertion point, 10 scroll bar, 11 status bar showing page 1 of 1 and word count, 12 view buttons, 13 zoom slider](/images/csc272/word-window.svg)

| Part | What it is for |
|---|---|
| **Quick Access Toolbar** | One-click Save, Undo, Redo (customisable) |
| **Title bar** | The document's name and the program (`Document1 - Word`) |
| **Minimize / Maximize (Restore) / Close** | Shrink the window to the taskbar, fill the screen (or restore it), or close the document — closing the last document may also exit Word |
| **FILE tab** | Backstage view: New, Open, Save, Save As, Print, Share, Export, Close, Options |
| **Ribbon tabs → groups → commands** | All the tools, arranged by activity |
| **Dialog Box Launcher** | The small diagonal arrow ↘ in a group's corner: opens a dialog box or task pane with more options |
| **Ruler** | Shows margins, indents (the ▽/△ markers) and tab stops — VIEW → Ruler turns it on |
| **Document area** | The page; the blinking **insertion point** shows where typing will appear |
| **Scroll bar** | Moves through long documents |
| **Status bar** | Page number (PAGE 1 OF 3), **word count**, proofing status, language |
| **View buttons** | Read Mode, Print Layout, Web Layout |
| **Zoom slider** | Magnifies the page on screen — it does **not** change the real font size |

### Views ("layouts")

The views are different ways of displaying the document while you work. Three have buttons on the status bar; all five are on the **VIEW** tab.

| View | Description |
|---|---|
| **Print Layout** | The **default**. Shows the document as it will appear on the printed page — margins, headers, footers, pictures |
| **Read Mode** | *New in 2013.* Maximises the document for reading in an **un-editable** view, with columns you page through. Its menus are FILE, **Tools** (Find, search with Bing) and **View** (Edit Document, Navigation Pane, Comments, **Page Colour** — None, Sepia, Inverse — Column Width, **Layout**: Column or Paper). If you close a document in Read Mode it reopens in Read Mode — choose **View → Edit Document** to return to Print Layout |
| **Web Layout** | The document as it would appear as a **web page** (no page breaks) |
| **Outline** | Simplifies the formatting so you can focus on the **structure** — headings can be promoted, demoted and moved with their text |
| **Draft** | Designed for **speed** of typing and editing (called **Normal** view in earlier Word); headers, footers and many pictures are hidden |

## The FILE Tab (Backstage View)

The **FILE** tab, at the top-left, **replaced the old File menu**. It opens a full-window **Backstage view** with commands that act on the **whole file**: **Info, New, Open, Save, Save As, Print, Share, Export, Close, Account, Options**. The ⮌ arrow (or **Esc**) returns you to the document.

### The Info menu

The **Info** page shows the document's properties (size, pages, words, author, dates) and three important buttons:

<Tabs>
<Tab label="Protect Document">

Controls **what changes other people can make** to a copy you send them.

| Option | What it does |
|---|---|
| **Mark as Final** | Makes the document **read-only** to signal it is finished: typing, editing commands and proofing marks are turned off and the document's **Status** property is set to *Final*. **It is not a security feature** — anyone who receives the file can click **Edit Anyway** and edit it again |
| **Encrypt with Password** | Scrambles the file so it can only be opened with the password. Use with caution: **if the password is forgotten the document cannot be recovered** |
| **Restrict Editing** | Allow only certain kinds of changes: tracked changes, comments, or filling in forms (optional password) |
| **Restrict Access** | Lets others **view** the document but limits what they can do (print, copy, edit), using Information Rights Management — needs an extra rights-management service |
| **Add a Digital Signature** | Signs the document so the recipient can **verify** who created it and that it has not been changed since — requires a digital certificate (a purchased/issued ID) |

</Tab>
<Tab label="Inspect Document">

**Check for Issues** before you share a file:

| Option | Checks for |
|---|---|
| **Inspect Document** | **Hidden data and personal information**: comments, tracked changes, document properties/author name, hidden text, headers and footers — and offers to remove them |
| **Check Accessibility** | Content people with disabilities might find hard to read (missing alt text on pictures, etc.) |
| **Check Compatibility** | Features that **won't work in earlier versions of Word** — useful when you must **Save As** Word 97–2003 (`.doc`) |

</Tab>
<Tab label="Versions">

**Manage Versions / Manage Document** lets you open earlier AutoRecover versions of the file and **Recover Unsaved Documents** after a crash or when you closed without saving.

</Tab>
</Tabs>

## The Ribbon

The **Ribbon** is present in **all** the Office applications, with differently named tabs and commands, though some tabs (HOME, INSERT, REVIEW, VIEW) are common to all. It has three basic components:

| Component | Meaning | Example |
|---|---|---|
| **Tabs** | Across the top; each represents an **activity area** | HOME |
| **Groups** | Each tab has several groups showing **related items together** | Font |
| **Commands** | A **button**, an **icon**, a **box** to enter information, or a **menu** | Bold, Font Size box |

**ScreenTips:** rest the mouse on any command (without clicking) and Office shows its **name and what it does** — and its keyboard shortcut. Try it.

<ExamTip>
The notes say Word has "seven basic tabs". In fact Word 2013 shows **eight** besides FILE — **HOME, INSERT, DESIGN, PAGE LAYOUT, REFERENCES, MAILINGS, REVIEW, VIEW** — because the **DESIGN** tab was added in 2013. Excel 2013 has seven. If asked, list the tabs by name; that is what earns the marks.
</ExamTip>

### Tab by tab

| Tab | Key groups and commands |
|---|---|
| **HOME** | Opens by default; the tools used most often. **Clipboard** (Cut, Copy, Paste/Paste Special, **Format Painter** — copies the formatting of one paragraph to another), **Font** (font, size, bold, italic, underline, superscript, subscript, **Change Case**), **Paragraph** (bullets and numbering, alignment, line spacing, indentation, shading, **Sort**, **Show/Hide ¶**), **Styles** (consistent formats for paragraphs), **Editing** (Find, Replace, Select) |
| **INSERT** | **Cover Page**, Blank Page, **Page Break**; **Tables**; **Pictures**, Online Pictures, Shapes, **SmartArt**, Chart, Screenshot; Hyperlink; Comment; **Header, Footer, Page Number**; Text Box, WordArt, Drop Cap; **Equation**, Symbol. Inserting a graphic, table or shape makes a **contextual tab** appear |
| **DESIGN** | *New in 2013* — overall document formatting in one place: **Themes** (the look of headings, fonts and colours), style sets, colours, fonts, paragraph spacing; **Watermark** (faint text or picture behind the text, e.g. "CONFIDENTIAL"), **Page Colour**, **Page Borders** |
| **PAGE LAYOUT** | **Page Setup**: margins, **orientation**, paper size, **columns** (newspaper style), **breaks** (start text on a new page; section breaks); paragraph indents and spacing; arranging pictures (Wrap Text, Position) |
| **REFERENCES** | **Table of Contents**, **footnotes/endnotes**, **citations and bibliography**, **captions** and tables of figures, **index** — tools for long, academic documents |
| **MAILINGS** | **Envelopes, Labels** and **Mail Merge** — sending the same letter with small personal differences to many people, from a table of their details |
| **REVIEW** | Proofing: **Spelling & Grammar**, **Thesaurus**, **Word Count**, set **Language**; **Comments**; **Track Changes**, Accept/Reject; Compare; Restrict Editing |
| **VIEW** | Views (Read Mode, Print Layout, Web Layout, Outline, Draft); Show **Ruler**, Gridlines, **Navigation Pane**; Zoom; **Window**: New Window, Arrange All, **Split**, **View Side by Side** with **Synchronous Scrolling**; Macros |

### The Equation tool

INSERT → **Equation** (or **Alt+=**) inserts a maths zone where you build an equation **exactly as it should appear** — fractions, powers, roots, Greek letters, integrals — using the EQUATION TOOLS DESIGN tab. The equation is treated as **one object**, so it moves as a unit instead of scattering when you edit the text around it. You will use it in the advanced-features lesson.

### Contextual tabs

Some tabs appear **only when you need them**. Select an **object** and its tools appear; click away and they disappear (you return to the HOME tab). Contextual tabs are easy to spot by their **distinctive colour** and a heading above them, and each set has one or two tabs:

| Select… | Contextual tab(s) |
|---|---|
| A picture | **PICTURE TOOLS → FORMAT** (Picture Styles, Wrap Text, Crop…) |
| A table | **TABLE TOOLS → DESIGN** and **LAYOUT** |
| A shape or text box | **DRAWING TOOLS → FORMAT** |
| SmartArt | **SMARTART TOOLS → DESIGN** and **FORMAT** |
| A chart | **CHART TOOLS → DESIGN** and **FORMAT** |
| The header/footer | **HEADER & FOOTER TOOLS → DESIGN** |
| An equation | **EQUATION TOOLS → DESIGN** |

### The Dialog Box Launcher

Some groups have a small **diagonal arrow ↘** in the lower-right corner — the **Dialog Box Launcher**. Clicking it shows **more options** for that group, usually in a **dialog box** you may recognise from older Word versions (e.g. the **Font** dialog, the **Paragraph** dialog, **Page Setup**), or in a **task pane** (e.g. the Clipboard or Styles pane).

## The Quick Access Toolbar (QAT)

The **Quick Access Toolbar** sits in the **upper-left corner**, next to (above) the FILE tab. It is **customisable** and **independent of the tab** that is displayed — its buttons stay the same whatever tab is open. By default it holds **Save**, **Undo** and **Redo**.

**To add a command:**

1. Find the command on its tab.
2. **Right-click** the command.
3. Choose **Add to Quick Access Toolbar**. The button now appears on the QAT.

(You can also click the small arrow at the end of the QAT, **Customize Quick Access Toolbar**, and tick common commands such as New, Open, Quick Print, Print Preview, Spelling.)

**To remove a button:** right-click it on the QAT → **Remove from Quick Access Toolbar**.

The QAT can be moved with **Show Below the Ribbon** from the same menu.

### Undo and Redo

Word remembers the changes you make during a session, so you can **undo** any number of them — typing and formatting alike — **as long as you have not exited the program**.

- **Undo** (**Ctrl+Z**): becomes active as soon as you change something; each click undoes the **last** action. The arrow beside Undo lists recent actions so you can undo several at once.
- **Redo** (**Ctrl+Y**): "undoes the Undo" — restores what you just undid. When there is nothing to redo, the same button becomes **Repeat** (also Ctrl+Y or **F4**), which repeats your last action (e.g. applying the same format elsewhere).

<Reveal question="1. List the three basic components of the Ribbon and give an example of each.">
**Tabs** — activity areas across the top, e.g. HOME. **Groups** — related commands within a tab, e.g. Font. **Commands** — buttons, icons, boxes or menus that perform actions, e.g. Bold or the Font Size box.
</Reveal>

<Reveal question="2. What are contextual tabs? Give two examples.">
Tabs that appear **only when a particular object is selected** and disappear when you click away; they are shown in a distinctive colour with a heading. Examples: **PICTURE TOOLS FORMAT** (when a picture is selected), **TABLE TOOLS DESIGN and LAYOUT** (when the cursor is in a table), CHART TOOLS, HEADER & FOOTER TOOLS.
</Reveal>

<Reveal question="3. Describe how to add a command to the Quick Access Toolbar and how to remove it.">
**Add:** right-click the command on its Ribbon tab → **Add to Quick Access Toolbar** (or use the Customize Quick Access Toolbar arrow). **Remove:** right-click the button on the QAT → **Remove from Quick Access Toolbar**.
</Reveal>

<Reveal question="4. Name the five views available in Word 2013 and state the default.">
**Read Mode, Print Layout, Web Layout, Outline, Draft**. **Print Layout** is the default and shows the document as it will be printed.
</Reveal>

<Reveal question="5. What is the use of the Inspect Document feature?">
It checks the document before sharing: **Inspect Document** finds hidden data and personal information (comments, tracked changes, author properties, hidden text) and removes it; **Check Accessibility** finds content hard for people with disabilities; **Check Compatibility** lists features that won't work in earlier versions of Word, useful before saving as .doc.
</Reveal>

<Takeaway>
- Launch Word by searching for it from Start (Windows 7/8/10); Office 2013 opens on the **Start Screen** (recent files + templates) — choose **Blank document**.
- New documents are called **Document1** and open in **Print Layout**. Other views: **Read Mode** (new, un-editable), **Web Layout**, **Outline**, **Draft**. Zoom changes the view, not the font size.
- **FILE tab** = Backstage view. **Info → Protect Document** (Mark as Final is *not* security; Encrypt with Password; Restrict Editing/Access; Digital Signature), **Inspect Document** (hidden data, accessibility, compatibility), **Versions**.
- Ribbon = **tabs → groups → commands**; ScreenTips explain commands; the **Dialog Box Launcher** ↘ opens more options; **contextual tabs** appear for selected objects.
- Word 2013 tabs: HOME, INSERT, **DESIGN** (new), PAGE LAYOUT, REFERENCES, MAILINGS, REVIEW, VIEW.
- **Quick Access Toolbar**: Save, Undo, Redo by default; right-click a command to add it. **Undo Ctrl+Z**, **Redo Ctrl+Y** — until you exit Word.
</Takeaway>

## Exam Tips

- "**On which tab / in which group would you find…**" is a favourite short question — practise with the quiz above until you can place Watermark, Columns, Breaks, Table of Contents, Track Changes, Word Count, Mail Merge and Show/Hide ¶ without thinking.
- Know **Mark as Final** vs **Encrypt with Password** and why Mark as Final is not security.
- Use the correct vocabulary: **tab, group, command, dialog box launcher, contextual tab, Backstage view, Quick Access Toolbar**.
- In the practical exam, **Ctrl+Z** is your friend — but it cannot bring back work lost by closing without saving, so save as you go.
