## Creating Your First Document

Launch Word and choose **Blank document**. Now type the following note **without pressing Enter at the end of each line**:

```text
I made myself a mud house, as perfect as could be. I was pleased with
myself. I thought I'd keep it and sleep in it. I also made some mud beds
and a pillow for myself. Then last night it rained and the house disappeared.
```

Notice that Word moves a word that does not fit onto the next line **by itself**. This is **word wrap**.

<ExamTip>
**Never press Enter to end lines inside a paragraph.** Enter means "end of paragraph". Pressing it at the end of every line creates uneven line breaks and many one-line paragraphs, which fall apart when you change the font, margins or alignment later. Press Enter only at the end of a paragraph (or a list item).
</ExamTip>

### The insertion point

The **blinking vertical bar** is the **insertion point**: whatever you type appears there. Move it by **clicking** where you want to type, or with the **arrow keys**, **Home/End** (start/end of line) and **Ctrl+Home/Ctrl+End** (start/end of document).

**Inserting text:** click just before the word *pleased* and type `very ` (with a space). The word is inserted and the rest of the text moves right to make room.

| Key | Effect |
|---|---|
| **Backspace** | Deletes the character to the **left** of the insertion point |
| **Delete** | Deletes the character to the **right** |
| **Enter** | Ends a paragraph and starts a new one |
| **Shift+Enter** | Line break *inside* the same paragraph |
| **Ctrl+Enter** | Page break — the next text starts on a new page |

### Selecting text

You must **select** (highlight) text before formatting, moving or copying it.

| To select… | Do this |
|---|---|
| Any amount | **Drag** across it with the mouse, or hold **Shift** and use the arrow keys |
| A word | **Double-click** it |
| A sentence | Hold **Ctrl** and click in it |
| A paragraph | **Triple-click** in it (click three times quickly) |
| A line | Click in the **left margin** beside it |
| The whole document | **Ctrl+A**, or HOME → Editing → **Select → Select All** |

## Saving a Document

**First save:**

1. Click the **FILE** tab.
2. Choose **Save** (for a new document it behaves like **Save As**).
3. Make sure **Computer** is highlighted; the right side shows recent folders and a **Browse** button.
4. Click **Browse** — the familiar **Save As** window opens.
   - **Name** the file (the name cannot contain `\ / : * ? " < > |`).
   - Select the **location** (folder). *Check the location before you click Save* — in the exam it must be your named folder on the flash drive.
   - Click **Save**.

**Saving changes later:** click **Save** on the Quick Access Toolbar, press **Ctrl+S**, or FILE → Save. The file keeps its name and location.

| Command | Use it when… |
|---|---|
| **Save** (Ctrl+S) | Updating the same file |
| **Save As** (F12) | Saving a **copy** with a **new name**, in a **new location**, or in a **different format** |

Save As types include **Word Document (.docx)**, **Word 97–2003 Document (.doc)**, **PDF (.pdf)**, **Word Template (.dotx)**, **Rich Text Format (.rtf)** and **Plain Text (.txt)**.

## Closing and Opening

**Closing:** click the **✕** in the top-right corner (or FILE → **Close**). If there are unsaved changes Word asks *"Do you want to save changes…?"* — **Save** keeps them, **Don't Save** discards them, **Cancel** returns to the document.

**Opening:**

1. FILE → **Open** (or **Ctrl+O**).
2. Pick a **Recent** document, or **Computer → Browse** and go to the folder.
3. **Double-click** the document's name (or select it and click **Open**).

### Pick Up Where You Left Off

New in Word 2013: when you reopen a long document, Word remembers **where you were working** when you saved and closed it. A box pops out on the right — *"Welcome back! Pick up where you left off:"* — showing the heading/section you were last editing and **how long ago**. Click it to jump straight there.

## Character Formatting

Word has many **character formats** (bold, italic, underline, colour…). The simplest method: **select the text**, then choose the format from the **HOME → Font** group or the **Mini Toolbar**.

### The Mini Toolbar

When you select text and point at it, a small **Mini Toolbar** pops up with the most-used formatting commands (font, size, bold, italic, colour, bullets, styles). It saves switching back to the HOME tab when you are working on another tab. Move the mouse away and it **fades** until it disappears.

### The Font group

| Command | Shortcut | Example / notes |
|---|---|---|
| **Bold** | Ctrl+B | **important** |
| **Italic** | Ctrl+I | *titles of books* |
| **Underline** | Ctrl+U | the arrow offers double, thick, dotted, wavy and coloured underlines |
| **Strikethrough** | — | a single line through the text |
| **Subscript** | Ctrl+= | H₂O, CO₂ |
| **Superscript** | Ctrl+Shift++ | 21ˢᵗ, x², 10⁶ |
| **Change Case** | Shift+F3 cycles | **Sentence case.**, **lowercase**, **UPPERCASE**, **Capitalize Each Word**, **tOGGLE cASE** |
| **Font Colour** | — | pick a colour, or **More Colours…** for the full palette |
| **Text Highlight Colour** | — | like a highlighter pen |
| **Font** and **Font Size** | Ctrl+Shift+F / Ctrl+Shift+P | Word's default is **11-point Calibri**; Word comes with more than 150 fonts |
| **Grow / Shrink Font** | Ctrl+] / Ctrl+[ | one size step up or down |
| **Clear All Formatting** | Ctrl+Space (characters) | removes all formatting from the selection |

Selecting everything first (**Ctrl+A**) lets you change the font of the whole document at once.

**Change Case** is a life-saver when you notice you have typed a whole paragraph with **Caps Lock** on: select it, then Change Case → **Sentence case**.

The **Font dialog box** (Dialog Box Launcher on the Font group, or **Ctrl+D**) has every option in one place, including effects such as **Small Caps**, **All Caps**, **Double strikethrough**, **Hidden**, and **Character Spacing** — and **Set As Default** to change the default font for new documents.

### Format Painter

**Format Painter** (HOME → Clipboard) **copies the formatting** of one piece of text or paragraph and applies it to another:

1. Click in the text whose formatting you like.
2. Click **Format Painter** — the pointer becomes a paintbrush.
3. Drag across the text to format.

**Double-click** Format Painter to apply the same formatting to several places; press **Esc** to stop.

## Paragraph Formatting

Paragraph formats apply to **whole paragraphs** — you just need the insertion point *in* the paragraph (or select several paragraphs).

### Alignment

| Button | Shortcut | Effect |
|---|---|---|
| **Align Left** | Ctrl+L | The **default** — text starts at the left margin; right edge is ragged |
| **Center** | Ctrl+E | Each line centred between the margins — titles |
| **Align Right** | Ctrl+R | Text lines up on the right margin — dates, addresses |
| **Justify** | Ctrl+J | Aligns text **evenly at both the left and right** margins (extra space is added between words); the last line stays left-aligned |

### Line spacing

1. Select the paragraph (**triple-click** it) or click in it.
2. HOME → Paragraph → **Line and Paragraph Spacing**.
3. Choose from **1.0, 1.15, 1.5, 2.0, 2.5, 3.0** (Word 2013's Normal style uses 1.08). **Line Spacing Options…** opens the Paragraph dialog for exact settings (At least, Exactly, Multiple).

Shortcuts: **Ctrl+1** single, **Ctrl+5** 1.5, **Ctrl+2** double spacing.

### Paragraph spacing (space before/after)

Many people create space between paragraphs by pressing **Enter** several times — this causes trouble later when text moves. Instead:

1. Click inside the paragraph.
2. **Line and Paragraph Spacing** → **Add Space Before Paragraph** / **Add Space After Paragraph**,
   **or** PAGE LAYOUT → Paragraph → **Spacing Before / After** — click the arrows to increase the space (in points).

### Bullets and numbered lists

Bulleted and numbered lists make documents more readable by setting off key points or steps.

**As you type (AutoFormat):**

1. Put the insertion point at the start of the first line of the list.
2. Type `*` (for bullets) or `1.` (for numbers), then press the **Spacebar** and type the first item.
3. Press **Enter** — Word continues the list automatically. Type the next item, and so on.
4. Press **Enter twice** (or Backspace) to end the list.

**With the Ribbon:** select the lines, then click **Bullets** or **Numbering** (HOME → Paragraph). The **arrow** beside each lets you choose a different symbol or numbering format (1. 2. 3., a) b) c), i. ii. iii.) or **Define New Bullet/Number Format**. **Multilevel List** creates sub-levels (1, 1.1, 1.1.1).

### Sorting a list

1. Select the text to sort (e.g. a list of names).
2. HOME → Paragraph → **Sort** — the *Sort Text* dialog opens.
3. Under **Sort by**, choose **Paragraphs** (or a field/column number).
4. Choose the **Type**: **Text**, **Number** or **Date**.
5. Choose **Ascending** (A→Z, 0→9) or **Descending** (Z→A).
6. If the list has a heading you do not want sorted, select **Header row** under *My list has*.
7. Click **OK**.

### Show/Hide ¶

**Show/Hide ¶** (HOME → Paragraph, **Ctrl+Shift+8**) displays **non-printing characters**: **¶** at the end of every paragraph, **·** for each space, **→** for tabs, and page/section breaks. It tells you *what is where* — invaluable when spacing looks wrong or you need to delete a stray break. They never print.

## Formatting Lab

Try everything above on a real document. **Select text by dragging** (on a phone: long-press and drag the handles), then use the buttons. The task list ticks itself as you complete each job. Things to notice:

- If nothing is selected, **character** formats apply to the whole paragraph here (real Word formats the word at the insertion point).
- Drag the **ruler markers**: the **top ▽** is the **first-line indent**, the **bottom △** is the **hanging indent**, the small **rectangle** moves both (the **left indent**), and the △ on the right is the **right indent**. The status bar shows the result.
- Switch on **¶** to see paragraph marks and spaces.

## Practice Questions

<MCQ question="You typed a paragraph and pressed Enter at the end of every line. What will happen when you later change the margins?">
<Option>Nothing — Word ignores the Enter presses</Option>
<Option correct>The lines break unevenly because each line is now a separate paragraph</Option>
<Option>Word automatically joins the lines back together</Option>
<Option>The document becomes read-only</Option>
<Explain>Enter ends a paragraph. With a paragraph mark at every line end, the text can no longer re-wrap, so changing the margins, font or alignment leaves ragged, broken lines. Let word wrap handle line ends.</Explain>
</MCQ>

<MCQ question="Which option sets text evenly along both the left and right margins?">
<Option>Center</Option>
<Option>Align Right</Option>
<Option correct>Justify</Option>
<Option>Distributed indent</Option>
<Explain>Justify (Ctrl+J) spreads the words so both edges are straight, as in newspapers and books.</Explain>
</MCQ>

<MCQ question="Which is the correct way to show 'CO2' with a small 2 below the line?">
<Option>Select the 2 and click Superscript</Option>
<Option correct>Select the 2 and click Subscript (Ctrl+=)</Option>
<Option>Select CO2 and reduce the font size</Option>
<Option>Select the 2 and use Change Case</Option>
<Explain>Subscript places characters below the baseline (H₂O, CO₂). Superscript raises them (x², 21st).</Explain>
</MCQ>

<Reveal question="1. Differentiate between Save and Save As.">
**Save** (Ctrl+S) stores changes in the **same file** with the same name and location. **Save As** (F12) creates a **new copy** — with a different name, in a different location, or in a different format (e.g. .doc for Word 97–2003, or PDF). The first save of a new document always asks for a name and location (it behaves like Save As).
</Reveal>

<Reveal question="2. What is the Mini Toolbar?">
A small pop-up toolbar of frequently used formatting commands (font, size, bold, italic, colour, bullets…) that appears when you select text and point at it, so you can format quickly without switching to the HOME tab. It fades away when you move the mouse off it.
</Reveal>

<Reveal question="3. List the five Change Case options and explain when you would use Change Case.">
**Sentence case.**, **lowercase**, **UPPERCASE**, **Capitalize Each Word**, **tOGGLE cASE**. Use it to fix text typed in the wrong case (e.g. a paragraph typed with Caps Lock on) without retyping: select the text → HOME → Font → Change Case → choose the option.
</Reveal>

<Reveal question="4. Why should you use 'Space Before/After' instead of pressing Enter several times between paragraphs?">
Extra Enter presses create **empty paragraphs** that move with the text and cause uneven spacing, blank lines at the top of pages and layout problems later. Space Before/After is part of the paragraph's formatting, stays consistent, and can be changed for all paragraphs at once.
</Reveal>

<Reveal question="5. Describe how to sort a list of names in descending order, keeping the heading at the top.">
Select the list including its heading → HOME → Paragraph → **Sort** → Sort by **Paragraphs**, Type **Text**, choose **Descending** → under *My list has* choose **Header row** → **OK**.
</Reveal>

<Reveal question="6. What does Show/Hide ¶ do?">
It displays **non-printing formatting marks** — ¶ paragraph marks, dots for spaces, arrows for tabs, and page/section break markers — so you can see exactly how the document is built and find unwanted spaces or breaks. The marks do not print.
</Reveal>

<Takeaway>
- Let **word wrap** end lines; press **Enter** only to end a paragraph. The **insertion point** marks where text goes; **select** before formatting (double-click = word, triple-click = paragraph, Ctrl+A = all).
- **Save** (Ctrl+S) updates the file; **Save As** (F12) makes a copy with a new name, place or format. Check the location before saving. Close with ✕ and answer the save prompt. Word 2013 offers **Pick Up Where You Left Off**.
- Character formats (HOME → Font / Mini Toolbar): bold, italic, underline, strikethrough, **subscript** (H₂O), **superscript** (21st), **Change Case**, colour, font, size (default **Calibri 11**), clear formatting; Font dialog via the launcher. **Format Painter** copies formatting.
- Paragraph formats: **alignment** (left default, centre, right, **justify** = both edges), **line spacing** 1.0–3.0, **space before/after**, **bullets/numbering** (type `*` or `1.` + space), **Sort** (text/number/date, ascending/descending, header row), **Show/Hide ¶**.
</Takeaway>

## Exam Tips

- Practical questions often say "type three paragraphs and format them…". Type first, **then** format — and never break lines with Enter.
- **Subscript vs superscript** and the **Change Case** options appear in short questions; have an example ready for each.
- **Justify** is the answer to "aligns text evenly at both margins".
- Show your marker you know the **ribbon path**: e.g. "HOME tab → Paragraph group → Sort → Descending → Header row → OK".
- If formatting behaves strangely, switch on **¶** — you will usually find extra paragraph marks or spaces.
