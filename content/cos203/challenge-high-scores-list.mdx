# Challenge: Create a High Scores List

Now that you understand how to read and write structured data using the `csv` module, it's time to build a real-world data processing pipeline.

Imagine you are a backend developer for a popular multiplayer game. Every time a game ends, the server logs the player's name and their score into a massive raw log file called `scores.csv`. 

Because players play hundreds of games, their name appears in the log file dozens of times with different scores.

```text
name, score
LLCoolDave,23
LLCoolDave,27
red,12
LLCoolDave,26
tom123,26
```

## The Challenge Guidelines

Your goal is to write a script that processes this raw data and generates a clean, finalized leaderboard. 

You must read through the raw `scores.csv`, find the absolute highest score for each unique player, and save those results to a brand new file called `high_scores.csv`.

### Requirements

To pass this challenge, your script must accomplish the following:
1. **Read the raw data:** Use `csv.DictReader` to parse the input file.
2. **Process and filter:** You must keep track of the highest score seen so far for each player. If you see "LLCoolDave" score a 23, and later see him score a 27, you must update his high score to 27. *(Hint: A Python Dictionary is the perfect tool for tracking unique names).*
3. **Write the output:** Use `csv.DictWriter` to create `high_scores.csv`, featuring a header row of `name` and `high_score`, followed by the filtered data.

---

## Example Solution Walkthrough

Data processing scripts generally follow an "ETL" architecture: **Extract, Transform, Load**. Let's break down the logic using this industry-standard approach.

### Step 1: Extract (Read the Data)

First, we establish our file paths and open the raw data file. We will create an empty dictionary called `tracking_dict`. We will use the player's name as the Key, and their highest score as the Value.

```python
import csv
from pathlib import Path

input_path = Path("scores.csv")
tracking_dict = {}

with input_path.open(mode="r", encoding="utf-8", newline="") as file:
    reader = csv.DictReader(file)
    
    for row in reader:
        player_name = row["name"]
        
        # CRITICAL: We must cast the string to an integer so we can do math comparisons!
        # Note the space in " score" - we must match the column header exactly!
        current_score = int(row[" score"]) 
        
        # If the player is new, OR if their current score is better than their saved score:
        if player_name not in tracking_dict or current_score > tracking_dict[player_name]:
            # Update the record!
            tracking_dict[player_name] = current_score
```

> **The Spacing Trap:** Real-world data is messy. In the raw CSV file, the header is literally `name, score`. Notice the space after the comma. This means the key in our dictionary isn't `"score"`, it is `" score"`. We must account for this when extracting the data!

### Step 2: Transform (Format the Data for Writing)

At this point, our `tracking_dict` looks like this: `{"LLCoolDave": 27, "red": 12}`. 

However, `csv.DictWriter` requires a **List of Dictionaries**, where each dictionary represents a row. We must transform our data to look like this: `[{"name": "LLCoolDave", "high_score": 27}, ...]`.

```python
output_rows = []

for name, best_score in tracking_dict.items():
    
    # We construct a new row dictionary and append it to our list
    row_dict = {"name": name, "high_score": best_score}
    output_rows.append(row_dict)
```

### Step 3: Load (Write the Data)

Finally, we open the destination file and use `DictWriter` to dump our perfectly formatted list of dictionaries into the new CSV.

```python
output_path = Path("high_scores.csv")

with output_path.open(mode="w", encoding="utf-8", newline="") as file:
    
    # Setup the writer and define the columns
    writer = csv.DictWriter(file, fieldnames=["name", "high_score"])
    
    # Write the header row
    writer.writeheader()
    
    # Dump the data!
    writer.writerows(output_rows)
```

### The Complete Script

```python
import csv
from pathlib import Path

def generate_leaderboard():
    input_path = Path("scores.csv")
    output_path = Path("high_scores.csv")
    tracking_dict = {}
    
    # 1. EXTRACT
    with input_path.open("r", encoding="utf-8", newline="") as file:
        reader = csv.DictReader(file)
        for row in reader:
            name = row["name"]
            score = int(row[" score"]) 
            if name not in tracking_dict or score > tracking_dict[name]:
                tracking_dict[name] = score
                
    # 2. TRANSFORM
    output_rows = []
    for name, best_score in tracking_dict.items():
        output_rows.append({"name": name, "high_score": best_score})
    
    # 3. LOAD
    with output_path.open("w", encoding="utf-8", newline="") as file:
        writer = csv.DictWriter(file, fieldnames=["name", "high_score"])
        writer.writeheader()
        writer.writerows(output_rows)

if __name__ == "__main__":
    generate_leaderboard()
    print("Leaderboard generated successfully.")
```

## Key Takeaways
- **ETL Architecture:** Breaking data tasks into Extract, Transform, and Load phases keeps your code clean and logical.
- **Dictionaries are powerful:** Using a dictionary to track state (like the highest score for a specific user) is a fundamental algorithmic pattern you will use repeatedly in your career.
- **Data Cleanup:** When extracting data from external files, you must always be hyper-vigilant about data types (casting strings to integers) and formatting (rogue spaces in column names).

## Exam Tips
- **The Transformation Step:** A very common mistake is trying to pass `tracking_dict` directly to `writer.writerows()`. Remember that `writerows()` expects a *List*, not a single massive dictionary. You must execute the transformation step.
