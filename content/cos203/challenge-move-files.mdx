# Challenge: Move All Image Files to a New Directory

Now that you understand how to navigate the file system and manipulate files, it is time to put your skills to the test in a practical automation challenge.

Imagine you work as an IT administrator. An employee has stored all of their work documents in a massive folder called `documents/`. Unfortunately, they have completely disorganized the folder, mixing their vacation photos (`.png`, `.gif`, `.jpg`) deep within various subfolders alongside their actual work documents.

Your boss has asked you to clean up the mess. 

## The Challenge Guidelines

Write a Python program that scans the `documents/` folder, finds every single image file regardless of how deeply it is nested in subfolders, and moves them all into a brand new folder called `images/`.

### Requirements

To pass this challenge, your script must accomplish the following:
1. **Create the target directory:** The script must create the `images/` directory. It must not crash if the script is run twice and the `images/` folder already exists.
2. **Recursive Searching:** The script must search for `.png`, `.gif`, and `.jpg` files. It must look in the root folder, and every subfolder inside it.
3. **Move the files:** The script must move the files from their original location into the new `images/` folder.

---

## Example Solution Walkthrough

If you are stuck, let's break down the logic step-by-step to arrive at a clean, professional automation script.

### Step 1: Establish the Architecture

First, we need to map out our locations using `Path` objects. We define where we are looking (`documents_dir`) and where we are sending the files (`images_dir`).

```python
from pathlib import Path

# Setup our base paths
base_dir = Path.cwd() # Assume we run the script next to the folders
documents_dir = base_dir / "documents"
images_dir = base_dir / "images"
```

### Step 2: Build the Infrastructure

Before we can move any files, we must guarantee that the destination exists. We use `.mkdir()` with the `exist_ok` safety net.

```python
# Create the images folder. If it's already there, do nothing.
images_dir.mkdir(exist_ok=True)
```

### Step 3: Search and Relocate

We have three different file extensions to look for. Instead of writing the search logic three separate times (violating the DRY principle), we will place our extensions in a list and loop through them.

For the search itself, we MUST use `.rglob()` (Recursive Glob), because the instructions state the images are hidden deep within subfolders. `.glob()` would only scratch the surface.

```python
# List of extensions we care about
extensions = ["*.png", "*.gif", "*.jpg"]

for ext in extensions:
    # Use rglob to dig infinitely deep for matches
    for file_path in documents_dir.rglob(ext):
        
        # We construct the destination path. 
        # We take the destination folder, and stitch the original file name onto the end of it.
        target_path = images_dir / file_path.name
        
        # Move the file!
        file_path.replace(target_path)
        print(f"Successfully moved: {file_path.name}")
```

### The Complete Script

```python
from pathlib import Path

def sort_images(base_path_str):
    # 1. Setup Paths
    base_dir = Path(base_path_str)
    documents_dir = base_dir / "documents"
    images_dir = base_dir / "images"

    # 2. Build Infrastructure
    images_dir.mkdir(exist_ok=True)

    # 3. Search and Move
    for ext in ["*.png", "*.gif", "*.jpg"]:
        for file_path in documents_dir.rglob(ext):
            target_path = images_dir / file_path.name
            file_path.replace(target_path)

if __name__ == "__main__":
    # Execute the automation script
    sort_images(Path.cwd())
```

## Key Takeaways
- **Automation:** Python is incredibly powerful for automating tedious administrative tasks. A task that would take a human an hour of clicking and dragging can be done by a Python script in 0.2 seconds.
- **`.rglob()` Mastery:** Recursive globbing is the ultimate tool for finding needles in haystacks.
- **Dynamic Path Construction:** Moving a file requires an exact destination path. Sticking the original `.name` onto the end of the new directory path (`images_dir / file_path.name`) is the standard way to preserve file names when moving them.

## Exam Tips
- **The Destructive `.replace()`:** Always double-check what is being passed to `.replace()`. If you accidentally loop through 10 images and pass `images_dir / "photo.jpg"` as the target for *all* of them, you will overwrite the file 10 times, leaving you with only 1 surviving image. The target path must be dynamically generated for each file.
