# Common File System Operations

In the previous topic, we learned how to use `pathlib` to point at specific locations on our computer's hard drive. However, merely pointing at things isn't very useful. We need to be able to actually manipulate the file system.

In this topic, we will use Python to act like a virtual assistant—creating folders, creating files, moving data around, searching for specific documents, and deleting the trash.

> **Real World Analogy:** If learning file paths was like learning how to read a map to find an empty plot of land, learning file system operations is like learning how to bring in the construction crew to pour the foundation, build the house, and eventually demolish it.

## 1. Creating Folders (Directories)

To create a new folder on your computer, we use the `.mkdir()` (Make Directory) method on a Path object.

### Worked Example 1: Creating a Directory safely

```python
from pathlib import Path

# 1. We create the Path object pointing to where we WANT the folder to be.
new_folder_path = Path.home() / "my_new_project"

# 2. We command Python to create the folder on the hard drive.
# exist_ok=True prevents the program from crashing if the folder already exists.
new_folder_path.mkdir(exist_ok=True)
```

**The Missing Parents Problem:**
What happens if you try to create a deeply nested folder, like `Path.home() / "folder_A" / "folder_B" / "folder_C"`, but `folder_A` doesn't exist yet? 

Python will panic and throw a `FileNotFoundError`. You cannot create a room inside a house if the house hasn't been built! To solve this, we tell `.mkdir()` to automatically build any missing parent folders using `parents=True`.

```python
deep_folder = Path.home() / "folder_A" / "folder_B" / "folder_C"

# This builds folder_A, then folder_B, then folder_C all at once!
deep_folder.mkdir(parents=True, exist_ok=True)
```

## 2. Creating Files

Creating an empty file is very similar to creating a folder. We point to the location, and then we use the `.touch()` method.

*(The term "touch" comes from old Linux commands, originally meant to update the timestamp on a file, but commonly used to create new, empty files).*

```python
# 1. Set the path
my_file_path = deep_folder / "notes.txt"

# 2. Create the file
my_file_path.touch()

print(my_file_path.exists()) # Output: True
```

Unlike `.mkdir()`, the `.touch()` method does *not* have a `parents=True` parameter. If you try to touch a file inside a folder that doesn't exist, the program will crash. You must always `mkdir()` the parent folder before you `touch()` the file.

## 3. Searching for Files (Iteration and Globbing)

If a folder has hundreds of files in it, we often want to write a script to look through them all to find specific data.

### Basic Iteration
To simply list everything directly inside a single folder, we use `.iterdir()`. This returns a list of Path objects for every file and folder inside.

```python
my_folder = Path.home() / "Documents"

# Loop through every item in the folder
for item in my_folder.iterdir():
    print(item.name)
```

### Searching with Glob
`.iterdir()` is a blunt instrument. What if we *only* want to find PDF files? We use **Globbing**. 

Globbing uses wildcard characters (like the asterisk `*`) to act as placeholders. The pattern `*.pdf` means "I don't care what the name of the file is, as long as it ends in .pdf".

```python
# .glob() searches the immediate folder for matching patterns
for pdf_file in my_folder.glob("*.pdf"):
    print(f"Found a PDF: {pdf_file.name}")
```

### Recursive Searching with RGlob
The biggest limitation of `.iterdir()` and `.glob()` is that they are "shallow." They only look in the immediate folder. If you have a PDF hidden three folders deep, they won't see it.

To search a folder, and every folder inside that folder, and every folder inside *that* folder, we use **Recursive Globbing** via `.rglob()`.

```python
# .rglob() searches the current folder AND all sub-folders infinitely deep!
for any_pdf_anywhere in my_folder.rglob("*.pdf"):
    print(f"Found a deeply hidden PDF: {any_pdf_anywhere}")
```

## 4. Moving and Deleting

### Moving Files
To move a file, we use the `.replace()` method. You call the method on the original file path, and pass the new destination path as the argument.

```mermaid
flowchart LR
    Source[C:/folder_A/data.txt] --> | .replace() | Dest[C:/folder_B/data.txt]
```

### Worked Example 2: Moving a File

```python
from pathlib import Path

source_file = Path.home() / "Downloads" / "report.txt"
destination = Path.home() / "Documents" / "report.txt"

# Assuming source_file exists, this moves it to the destination
# WARNING: If the destination file already exists, it will be silently OVERWRITTEN.
source_file.replace(destination)
```

### Deleting Files and Folders
Deleting data via Python bypasses your computer's Recycle Bin. Once the code executes, the data is gone forever. **Use extreme caution.**

- **To delete a single file:** Use `.unlink()`.
- **To delete an empty folder:** Use `.rmdir()`.

```python
trash_file = Path.home() / "Downloads" / "junk.txt"

# Delete the file
# missing_ok=True prevents a crash if the file was already deleted
trash_file.unlink(missing_ok=True)
```

If you try to use `.rmdir()` on a folder that contains files, Python will refuse to do it and throw an `OSError` to protect you from accidentally deleting a massive directory tree. If you truly need to delete a folder full of files, you must use the `shutil.rmtree()` function from the built-in `shutil` module.

## Key Takeaways
- **Creating Data:** Use `.mkdir(parents=True, exist_ok=True)` for robust folder creation. Use `.touch()` to spawn empty files.
- **Searching:** Use `.glob("*.ext")` to search a single folder for specific file types. Use `.rglob("*.ext")` to search deeply through all subfolders.
- **Moving:** Use `.replace(destination)` to move files, but beware that it will ruthlessly overwrite existing files at the destination.
- **Deleting:** Use `.unlink()` for files and `.rmdir()` for empty folders. Deletions are permanent!

## Exam Tips
- **The `.touch()` trap:** Remember that `.touch()` cannot create missing parent folders. You must create the folders first.
- **Glob Patterns:** If asked how to find every python file regardless of how deep it is in the project, the answer is always recursive globbing: `path.rglob("*.py")`.
- **Replacing Directories:** The argument passed to `.replace()` must be the full path including the file name. `source.replace(Path("C:/folder"))` is incorrect; it must be `source.replace(Path("C:/folder/file.txt"))`.
