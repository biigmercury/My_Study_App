# Difference Equations

A difference equation is the discrete-time analogue of a differential equation. Instead of relating a function to its derivatives, it relates terms of a *sequence* to earlier terms. The theory mirrors ODEs almost exactly — same auxiliary equation, same three cases, same structure for the general solution.

## Sequences and Difference Equations

A **sequence** is an ordered list of numbers: $u_0, u_1, u_2, \ldots$ The index $n$ takes integer values.

**Examples:**
- Odd numbers: $u_n = 2n+1$: $1, 3, 5, 7, \ldots$
- Powers of 2: $u_n = 2^n$: $1, 2, 4, 8, \ldots$

A **difference equation** specifies a sequence by giving a rule that expresses each term using previous terms:

$$u_{n+k} + a_1 u_{n+k-1} + \cdots + a_k u_n = f(n) \tag{13.1}$$

This is a **linear** difference equation of **order** $k$.

**Real-world analogy:** Compound interest is a difference equation. If $u_n$ is your bank balance after $n$ years and the interest rate is $r$, then $u_{n+1} = (1+r)u_n$ — your balance next year equals this year's balance multiplied by $(1+r)$.

## Simple Cases

### Case: $u_{n+1} = au_n$ (Constant Ratio)

Solving inductively: $u_1 = au_0$, $u_2 = au_1 = a^2 u_0$, and in general:

$$u_n = a^n u_0 \tag{13.3}$$

Compare with the differential equation $y' = ky$, which has solution $y = Ce^{kx}$. Here $a$ plays the role of $e^k$ and $n$ plays the role of $x$.

### Case: $u_{n+1} = a_n u_n$ (Variable Ratio)

By the same inductive argument:

$$u_n = \left(\prod_{k=0}^{n-1} a_k\right) u_0 \tag{13.5}$$

This is the discrete analogue of $y = Ce^{\int a(x)\,dx}$.

### Case: $u_{n+1} = u_n + f_n$ (Additive Sequence)

Iterating: $u_1 = u_0 + f_0$, $u_2 = u_0 + f_0 + f_1$, and in general:

$$u_{n+1} = u_0 + \sum_{k=0}^{n} f_k \tag{13.7}$$

---

## The General First-Order Linear Difference Equation

$$u_{n+1} = a_n u_n + f_n \tag{13.8}$$

The general solution:

$$u_{n+1} = \left(\prod_{k=0}^{n} a_k\right) u_0 + \sum_{k=0}^{n}\left(\prod_{j=k+1}^{n} a_j\right) f_k \tag{13.9}$$

This parallels the integrating factor solution of first-order linear ODEs.

## Example 13.1 — Two Simple Equations

Solve:
**(a)** $y_{n+1} - y_n = 2^n$
**(b)** $y_{n+1} = \frac{n+5}{n+3} y_n$

**Solution (a):** This is $u_{n+1} = u_n + 2^n$ (form 13.6). Using (13.7):

$$y_{n+1} = y_0 + \sum_{k=0}^{n} 2^k = y_0 + (2^{n+1} - 1)$$

**Solution (b):** This is $u_{n+1} = a_n u_n$ with $a_n = \frac{n+5}{n+3}$. Using (13.5):

$$y_n = \left(\prod_{k=0}^{n-1}\frac{k+5}{k+3}\right)y_0$$

The product telescopes: $\prod_{k=0}^{n-1}\frac{k+5}{k+3} = \frac{(n+4)(n+3)}{4 \cdot 3} = \frac{(n+3)(n+4)}{12}$

So $y_n = \frac{(n+3)(n+4)}{12} y_0$.

## Example 13.2 — Amoeba Population

An amoeba population starts at 1000. Every 10 amoebas, one reproduces by cell division each hour. Find the size after 30 hours.

**Model:** Each amoeba reproduces at rate $\frac{1}{10}$ per hour, so:

$$y_{n+1} - y_n = \frac{1}{10}y_n \implies y_{n+1} = 1.1\,y_n$$

**General solution (from 13.3):**

$$y_n = (1.1)^n y_0 = (1.1)^n \cdot 1000$$

**After 30 hours:** $y_{30} = (1.1)^{30} \times 1000 \approx 17.449 \times 1000 = 17449$.

---

## Example 13.3 — Amoeba with External Source

Same population, but a leak adds 20 amoebas per hour:

$$y_{n+1} = 1.1\,y_n + 20$$

Using formula (13.9) with constant $a_n = 1.1$, $f_n = 20$:

$$y_{n+1} = (1.1)^{n+1} y_0 + 20\sum_{k=0}^{n}(1.1)^{n-k}$$

$$= 1000(1.1)^{n+1} + 20 \cdot \frac{(1.1)^{n+1} - 1}{1.1 - 1}$$

$$= 1000(1.1)^{n+1} + 200((1.1)^{n+1} - 1)$$

At $n = 29$ (30 hours):

$$y_{30} \approx 17449 + 200(17.449 - 1) \approx 17449 + 3290 = 20739$$

## Comparison: ODEs vs Difference Equations

| Concept | ODE | Difference Equation |
|---|---|---|
| Unknown | Function $y(x)$ | Sequence $y_n$ |
| Equation | $y' = ay$ | $y_{n+1} = ay_n$ |
| Solution | $y = Ce^{ax}$ | $y_n = Ca^n$ |
| First-order linear | $y' + Py = f$ | $y_{n+1} = ay_n + f_n$ |
| General solution | Integrating factor | Formula (13.9) |

---

## Key Takeaways

- A difference equation of order $k$ needs $k$ initial conditions to find a unique solution.
- For $u_{n+1} = au_n$, the solution is geometric: $u_n = a^n u_0$.
- The product formula (13.5) handles variable coefficients.
- The sum formula (13.7) handles additive forcing.
- The general first-order linear difference equation (13.8) has an explicit solution (13.9).

---

## Exam Tips

- Treat difference equations like ODEs — recognise the order (how many terms ahead), identify whether it's homogeneous, and apply the corresponding solution method.
- For constant-coefficient first-order: $y_{n+1} = ay_n + f_n$. If $f_n = 0$, solution is $y_n = Ca^n$. If $f_n$ is constant, find a particular solution by trying $y_n = A$ (constant).
- Memorise: $y_{n+1} = (1+r)y_n$ is compound interest at rate $r$; solution $y_n = (1+r)^n y_0$.
- When computing products $\prod a_k$, look for telescoping or geometric series.
- Population problems always start by setting up the recurrence relation from the verbal description.
